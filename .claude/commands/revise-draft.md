---
description: Переписать редакционный черновик по пометкам владельца и проверить заново
argument-hint: <дата YYYY-MM-DD> <draft_id> <путь к файлу с пометками>
---
Аргументы: $ARGUMENTS (дата, draft_id, путь к файлу пометок).
Режим безголовый: субагентов вызывай только синхронно (`run_in_background: false`), не завершай ход до шага 4.

1. Прочитай `runs/<дата>/drafts/<draft_id>.json` и файл пометок.
2. Определи новую версию: `<draft_id без суффикса -vN>-v2`, если такой файл есть — `-v3` и т. д.
3. Вызови субагента tg-editor (канал `tg_editorial`) или vk-editor (`vk_editorial`) — по полю `channel` черновика — с задачей: переписать черновик с учётом пометок, сохранив факты и источники; записать `runs/<дата>/drafts/<новый id>.json` (id внутри = новый id). Исследование — `runs/<дата>/research/<slug>.json`, slug = id без суффиксов `-r`/`-vN`.
4. Вызови субагента critic для нового черновика (вердикт в `runs/<дата>/verdicts/<новый id>.json`).
5. Последним сообщением выведи: путь к новому черновику и вердикт (ok, причина одной строкой).
Ничего не публикуй.
