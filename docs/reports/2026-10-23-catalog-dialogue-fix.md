# Просмотр моделей и контекст диалога

Ветка: `codex/project-review-content-sources`.

## Проблема

После «Поставь холодильники в генерацию» сервер спрашивал количество для 47
позиций. На «Покажи мне все модели» обработчик уточнял категорию заново,
а ответ «Холодильники» превращал в повторную постановку на генерацию.

В списке действий отсутствовал просмотр каталога. История слушателя хранила
JSON-намерения модели, но не фактический вопрос сервера про количество.

## Изменение

- `list_products`: чтение через существующий `Factory.resolve`; названия только
  из ответа каталога. Не вызывает enqueue, не создаёт партии или вопросы
  количества. Список охватывает доступные для генерации позиции, которые
  возвращает существующий resolve, а не архив уже обработанных товаров.
- Длинный ответ отправляется частями с учётом длины UTF-16 Telegram.
- API сохраняет итоговый текст и передаёт предыдущие завершённые обмены
  в `context.history`. Выбор количества и отмена кнопкой также попадают в историю.
- Слушатель предпочитает историю сервера локальным JSON-намерениям.
- Инструкции различают просмотр и генерацию, сохраняют текущую категорию
  в продолжении разговора. `context.capabilities` обеспечивает совместимость
  со старым сервером: просьба просмотра не превращается в генерацию.

## Проверка

Полный набор: 296 passed, 1 skipped (права Unix на Windows).
Покрыты 47 моделей, длинные имена с эмодзи, отсутствие записи в очередь и партии,
пустой список, фактический вопрос сервера, история кнопок, порядок сообщений,
повторная доставка и строгая проверка параметров.

Проверка подключённого ChatGPT без исполнения намерений: «Покажи мне все модели»,
ответ кнопкой «Холодильники», «Сначала покажи, какие есть».
Результаты сохранены локально в `runs/2026-10-23/catalog-intents-check.json`.

## Применение

Сервер ещё не обновлён. `CLAUDE.md` запрещает менять продакшен,
`deploy/INSTALL.md` требует подтверждения владельца для шагов на сервере.
После разрешения: сделать резервную копию кода `/opt/agents-my/orchestrator_bot`,
перенести изменённые файлы этого пакета, перезапустить только
`orchestrator-bot.service`, проверить сервис и перезапустить слушатель на ПК.
Проверка в боте — просмотр холодильников; публикация или генерация для проверки
не нужны. `.env`, состояние очередей, сервисы и исходники content-factory не меняются.
Откат — восстановить копию пакета и перезапустить тот же сервис.
