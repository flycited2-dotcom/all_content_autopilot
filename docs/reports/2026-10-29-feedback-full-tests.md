# Полная проверка исправления карточек — 29.10.2026

Основной отказ воспроизведён по реальной переписке через MCP «Мой Telegram».
Владелец написал про Beko B1RFNK292W: «На фото морозильный ларь, а должна быть морозильная камера»,
подтвердил исправление, а бот ответил, что карточка заменена/отменена/опубликована.
На деле это было самостоятельное задание №3859 без строки в `excel_items`.
Прежний обработчик ошибочно требовал обязательную принадлежность контент-заводу.

## Исправления

- Добавлен отдельный маршрут самостоятельных заданий. Сохраняются владелец, чат, аккаунт,
  режим и подпись; результат доставляет обычный фотоагент. Подавление его ответа, нужное
  для карточек контент-завода, здесь не применяется.
- Для потерянного ответа сначала ищется уже принятый job по `request_key`, а не отправляется
  ещё один рендер. Проверяются владелец, исходный job и неизменность сохранённого задания.
- Неполный исходник Beko показывал только внутренние ящики. Подготовлен отдельный подписанный
  эталон полного товара с официальной страницы; старые исходники и отчёты не переписаны.
  Эталон привязан к audit/job/SHA-256, имеет приоритет при исправлении; при подмене файла запуск запрещён.
- В поиске источников Beko RFNK из длинного описательного названия извлекается полный точный SKU.
  Суффиксы и различия моделей сохраняются. Официальный домен `beko.ru` добавлен к `beko.com`.
- Ошибки отдельных старых снимков больше не повторяются каждые несколько секунд и не блокируют
  синхронизацию остальных. Повторы и ожидание позднего исходника сохраняются в SQLite.
- Обновление отчёта без исходника не удаляет ранее проверенный исходник с сервера.
- Потерянный Telegram-ответ повторяется отдельно от рендера. Просроченный ввод не захватывает
  поздние сообщения; повтор callback не стирает замечание; список карточек имеет страницы.
- Неопределённая отправка сохраняется при смене диалога. Непривязанный результат и терминальный отказ
  больше не называются успешным исправлением.
- У самостоятельных заданий скрыта неподходящая кнопка публикации контент-завода и проверяется её маршрут.
- ASR распознаёт эхо подсказки, зацикливание и пустой ответ. На том же аудио выполняется один повтор
  без подсказки/VAD/предыдущего контекста; повторно подозрительный ответ не применяется.
