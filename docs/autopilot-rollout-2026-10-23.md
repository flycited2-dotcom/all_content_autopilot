# Подключение товарного автопилота — 23.10.2026

Ветка: `codex/photo-audit-agent`. Владелец подтвердил переключение VPS и ПК,
автоматическую передачу новых товарных фото в ChatGPT и пробу из десяти карточек.
Публикация в рабочие каналы при проверке не выполняется.

Включены полный справочник, выбор количества и моделей, контроль перед выгрузкой
и автоматическая передача замечаний генератору. Живой каталог содержит 489 брендов
и шесть источников; Xiaomi есть в каталоге. Старый список первых 60 брендов больше
не используется как основание отказать владельцу в заданном бренде.

Итоговые проверки разработки после подключения: 371 тест прошёл, один пропущен.
На подключённом ChatGPT
успешны четыре реальные проверки понимания команд без исполнения действий:
два телевизора Xiaomi, холодильники без числа, ручной выбор стиральных машин,
просмотр всех моделей из предыдущего контекста.

Приняты десять позиций из [состава пробы](autopilot-test-batch.md). Это подтверждение
постановки, а не десяти успешных генераций. Текущее состояние, сравнения и причины
удержания сохраняются в `runs/2026-10-23/autopilot/trial-review.md`.
Обновление: `python tools/autopilot_trial.py --report`.

Проба уже проверила реальную передачу из фотоагента в аудитор: исходное фото
LG F10B8LD7 одобрено по официальному эталону. Сгенерированная карточка Samsung
WW11CGP44CSBLP удержана из-за отсутствия проверенного официального фото.
Эти результаты не подтверждают качество остальных ещё не завершённых карточек.

Найдены проблемы существующего поиска: старые ссылки LG возвращают 404,
часть страниц отдаёт миниатюры ниже 400 px. Они отклоняются генератором.
Первый контроль Midea также выявил пропущенный региональный домен:
официальная страница [Midea Россия](https://www.midea.com/ru) перенаправляет на
`midearussia.ru`; домен добавлен в доверенные по этому подтверждению.
Предыдущие отчёты сохранены, задним числом в успешные не переписаны.

Первый контроль карточки LG F10B8LD7 использовал маленький эталон и удержал её
из-за недостатка детализации. Выбор изображения исправлен: предпочтение крупным
изображениям, реально указанным на странице точной модели, включая `srcset`.
Проверено официальное фото 1100×730. Повторный контроль той же карточки без новой
генерации обнаружил добавленные элементы дисплея и изменённую форму барабана.
Он вынес `regenerate`; первоначально удержанное задание автоматически не возобновлялось.

Окончательное удержание аудита первоначально запускало общий повтор Excel-конвейера.
Применена отдельная защита в `content_factory/orchestrator/excel_pipeline.py`:
удержание завершает этап, сетевые сбои сохраняют ограниченный повтор. Проверены
четыре случая: research/card × удержание/временная ошибка. Один уже созданный
технический повтор Midea №3788 отменён до начала; активные задания не прерывались.
Патч для просмотра: `integrations/cf-photo-audit-hold.patch`.
