# Партия мясорубок — исправление 25.10.2026

Работа ведётся в ветке `codex/photo-audit-agent`; исправления установлены на VPS
и рабочем ПК с резервными копиями. Повторно создавать шесть заданий не нужно.

## Найденные причины

- У четырёх Willmark основной сайт отдавал HTTP 503 со страницей реконструкции.
  Поиск останавливался на недоступном URL. Теперь сохраняет причины отказа и
  ищет другие доступные страницы точной модели; резервный аудит требует
  согласованности трёх независимых каталогов. Продавцы остаются дополнительными источниками.
- Домены `blackton.tv` и `jvc-rus.ru` отсутствовали в проверенном реестре.
  У Blackton основная фотография указана в HTML-микроразметке Product,
  которую программа не распознавала. Поддержка добавлена и проверена на реальной странице.
- Галерея JVC сортировалась по URL, из-за чего выбирались насадки вместо корпуса.
  Порядок основной галереи сохраняется. Аудитор дополнительно проверяет наличие
  основного товара; старое одобрение фотографии комплектующих отозвано и поставлено на повтор.
- В `WMG-3672GS` к артикулу были приклеены характеристики. Канонический артикул
  восстановлен, старый ключ учёта сохранён. Передача списка ключей через JSON
  исключает разделение одного товара по запятым в его старом названии.
- Опубликованные в июле WMG-2140S и WMG-2083W ошибочно засчитывались новой партии.
  Решение теперь сопоставляется с датой нового выбора и текущим этапом карточки.
- При перезапуске Планировщик оставлял дочернего аудитора, из-за чего два процесса
  конфликтовали при получении Telegram-сообщений. Добавлены блокировка одного
  экземпляра и выход после остановки родительского процесса.
- После позднего успешного аудита восстанавливалось задание, но партия могла
  оставаться завершённой с ошибками. Теперь она вновь открывается; партии,
  отменённые владельцем, не возобновляются.

## Проверка и текущее ограничение

Полный набор проверок: **426 passed, 1 skipped**. Основные фото JVC и Blackton
скачаны с сайтов производителей и просмотрены; макет JVC проверен с собранной
мясорубкой. Оба локальных API отвечают; слушатель и аудитор работают по одному экземпляру.

Шесть исходных позиций возобновлены без ручного создания дублей. Партия №18
содержит ровно шесть товаров. Новых опубликованных карточек в ней пока нет.
Подключённый ChatGPT сообщил `usage_limit`: дальнейшая независимая проверка
ожидает восстановления лимита, снимки и задания сохраняются. Время следующей
попытки не является временем гарантированного сброса лимита.
Уточнение по свежей проверке в 15:08: программный маршрут вернул точный код
`subscription_sharing_usage_limit_exceeded`. Это может быть ограничение
подключённого приложения; общий лимит обычного чата этим кодом не установлен.
Проверять область ограничения следует в [Usage](https://chatgpt.com/settings/usage).

Уточнение архитектуры: этот программный OAuth-маршрут не является подключением
к обычному ChatGPT Classic. Настройки браузера Work не переключают провайдера
аудитора. Независимый автоматический маршрут через обычный чат не реализован;
готовность локальных служб не означает завершения этой задачи.

WMG-2140S отдельно удержана: второй проход обнаружил неоднозначность отделки
и логотипа между каталогами. Это нерешённое соответствие источников, а не
успешная проверка. Оно не снимается ради получения шести формально готовых карточек.

Текущий снимок состояния: `runs/2026-10-25/grinder-status.md` и `grinder-status.json`.
Локальный макет для визуальной проверки: `runs/2026-10-25/jvc-jk-mg123-corrected-layout.png`.
Макет ещё не означает пройденный финальный аудит. Публикацию подтверждает владелец.
