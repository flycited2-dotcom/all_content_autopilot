## Проверка фотографии

1. Фотоагент завершает изображение, но ещё не кладёт его в очередь выгрузки.
2. Контролёр сохраняет точную копию результата и фото поставщика, SHA-256,
   номенклатуру, номер исходного задания и ревизию.
3. Отдельный запрос сначала ищет на подтверждённых доменах производителя.
   Затем при необходимости добавляет другие источники. До пяти подтверждённых
   страниц с фотографиями, разные домены, без заполнения списка случайными ссылками.
   При недоступности производителя используется проверяемый каталог точной модели.
   Каждый из шести признаков должен подтверждаться подходящим источником
   с уверенностью не ниже 0,85 в обоих проходах. Редакционная проверка надписей
   требует не ниже 0,9; это отдельный порог, не требование к ракурсу фотографии.
   Разногласия и разные варианты отделки удерживают карточку. Продавцы не
   объявляются официальными; отчёт отмечает `catalog_reference`.
4. Страница должна реально открываться и содержать точную модель со всеми
   суффиксами. Фото скачивается только по ссылке с этой страницы. Основное
   `og:image` при совпадении точной модели в заголовке страницы либо
   `Product.image` точной модели в JSON-LD даёт подтверждение
   связи фотографии с товаром. Также учитывается фото с точной моделью в
   `alt`/`title`, если заголовок страницы подтверждает этот товар. Ленивая загрузка
   `data-src` поддерживается; логотипы и заглушки отбрасываются.
   Поддерживается также микроразметка `Product` в HTML. В галерее сохраняется
   порядок производителя: основное фото раньше насадок; сортировка хешей URL
   для выбора картинки не используется. Одни комплектующие не заменяют целый товар.
   Обычные картинки страницы могут относиться к
   соседним товарам — сами по себе не дают автоматического одобрения.
5. ChatGPT получает реальные изображения: результат, фото поставщика и
   скачанные эталоны. Проверяет идентичность видимых признаков, дизайн, контур,
   относительные пропорции, цвет и детали. Фон, ракурс и свет не объявляются
   изменением товара. У комплектов должны проверяться все видимые блоки.
   Для автоматического одобрения необходимы два самостоятельных визуальных
   прохода. Сохранённое подтверждённое расхождение того же файла с тем же
   официальным эталоном не снимается повторным оптимистичным ответом.
6. Подтверждённое расхождение → конкретные замечания исходному генератору.
   Исправление использует тот же режим и его оформление. До двух исправлений
   (три версии с исходной); неопределённый результат не разрешает новую генерацию.
   При доказанном расхождении для исправления может использоваться проверенное
   фото точной модели. Помимо страницы и хеша требуется визуальное подтверждение,
   что эталон показывает основной товар и подходит для исправления. Неоднозначность
   сама по себе не разрешает замену фотографии.
   Каждая новая версия проходит контроль заново. Перед готовностью также проверяются
   текст, характеристики, читаемость и соответствие исходному заданию и эталонам оформления.
7. Если эталонов недостаточно, поиск недоступен, детали закрыты или превышен
   лимит исправлений — ручная проверка. Такая фотография не получает разрешения
   на выгрузку. Контроль фото не означает согласия владельца на публикацию.

Точные физические размеры в сантиметрах по фотографии без масштаба не измеряются.
Относительные пропорции можно сравнить с эталонами; окончательная проверка
физических размеров требует паспорта и измерения товара.

Доверенные домены задаются в `rules/photo-auditor-manufacturers.yaml`.
Список: Midea, Daichi, Beko, LG, Haier, Samsung, Xiaomi, Willmark, Blackton, JVC. Для остальных марок поиск работает, но до
проверки и добавления официального домена итог будет ручным. Домен нельзя
объявить официальным только потому, что модель так назвала сайт продавца.

При недоступности ChatGPT задача сохраняется в `waiting_provider`. Повтор идёт
с паузой с учётом Retry-After, без новой генерации. После восстановления связи
последнее решение возвращает то же задание в конвейер. Прочие ошибки проверки
имеют ограниченное число попыток; они не превращаются в автоматическое одобрение.

После отключения света сохраняются исходное фото, результат, ревизия и хеши.
Если сервер успел удалить входной файл неудачного задания, фотоагент восстанавливает
его из снимка аудитора. Если неизвестно, закончилась ли оплачиваемая генерация,
слепой повтор блокируется до разбора сохранённого результата.

Повторить проверку уже удержанного файла без генерации: `python -m photo_auditor
recheck <полный_id_проверки>`. Предыдущий отчёт и эталоны архивируются, номер
ревизии сохраняется. Отменённые задания автоматически не возобновляются.
Явная повторная проверка разрешена и для ранее одобренного файла: прежнее
разрешение при этом отзывается до завершения нового контроля.

Поиск товарных фотографий и характеристик использует подключённый ChatGPT,
без браузерного поля ввода. Характеристики проходят проверку дословного
наличия в скачанном тексте. Проверенные фото и факты сохраняются вместе,
чтобы после перерыва продолжить тот же этап без новой постановки.

описание V5 не является текущим режимом работы.
Локальная копия исходника и прежних настроек:
`runs/2026-10-23/autopilot/photo-agent-backup/`.
При откате остановить дорожки, вернуть сохранённый `remote_agent.py` и прежнее
`photo-audit.json`, затем запустить их снова. Не выпускать автоматически ранее задержанные
изображения только из-за выключения контроля.
