# Контроль фотографий — @foto_auditor_bot

Разработка в ветке `codex/photo-audit-agent`. Сервис работает на ПК отдельно от
оркестратора и не использует токен Никиты. Изменения действующего фотоагента
подготовлены как патч; рабочая копия фотоагента и VPS не изменены.

## Подключение токена

Токен не отправлять в чат, GitHub, файл настроек или командную строку.
Из папки проекта запустить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\set-photo-auditor-token.ps1
```

Откроется локальное окно со скрытым вводом. Приложение проверит через Telegram
`getMe`, что токен принадлежит именно `@foto_auditor_bot`. На Windows сохранит
его зашифрованным DPAPI для текущего пользователя в
`runs/private/photo-auditor.dat`. В Git файл не попадает. Отдельный секрет
локального API создаётся автоматически и также шифруется; выводить его не нужно.
Для консоли без графики: `python -m photo_auditor configure --console`.

Проверка готовности: `python -m photo_auditor status`. Команда показывает
только флаги подключения и количество задач, без токенов.

## Проверка фотографии

1. Фотоагент завершает изображение, но ещё не кладёт его в очередь выгрузки.
2. Контролёр сохраняет точную копию результата и фото поставщика, SHA-256,
   номенклатуру, номер исходного задания и ревизию.
3. Отдельный запрос сначала ищет на подтверждённых доменах производителя.
   Затем при необходимости добавляет другие источники. До пяти подтверждённых
   страниц с фотографиями, разные домены, без заполнения списка случайными ссылками.
4. Страница должна реально открываться и содержать точную модель со всеми
   суффиксами. Фото скачивается только по ссылке с этой страницы. Основное
   `og:image` при совпадении точной модели в заголовке страницы либо
   `Product.image` точной модели в JSON-LD даёт подтверждение
   связи фотографии с товаром. Обычные картинки страницы могут относиться к
   соседним товарам — сами по себе не дают автоматического одобрения.
5. ChatGPT получает реальные изображения: результат, фото поставщика и
   скачанные эталоны. Проверяет идентичность видимых признаков, дизайн, контур,
   относительные пропорции, цвет и детали. Фон, ракурс и свет не объявляются
   изменением товара. У комплектов должны проверяться все видимые блоки.
6. Подтверждённое расхождение с официальным эталоном → замечания и повторная
   генерация. Две повторные генерации максимум (три версии вместе с исходной).
   Каждая новая версия проходит контроль заново.
7. Если эталонов недостаточно, поиск недоступен, детали закрыты или превышен
   лимит исправлений — ручная проверка. Такая фотография не получает разрешения
   на выгрузку. Контроль фото не означает согласия владельца на публикацию.

Точные физические размеры в сантиметрах по фотографии без масштаба не измеряются.
Относительные пропорции можно сравнить с эталонами; окончательная проверка
физических размеров требует паспорта и измерения товара.

Доверенные домены задаются в `rules/photo-auditor-manufacturers.yaml`.
Начальный список: Midea, Daichi, Beko, LG, Haier, Samsung. Для остальных марок поиск работает, но до
проверки и добавления официального домена итог будет ручным. Домен нельзя
объявить официальным только потому, что модель так назвала сайт продавца.

При ошибке провайдера задача сохраняется. Повтор — с паузой с учётом Retry-After;
после трёх незавершённых проверок — ручной разбор, без автоматического допуска.

## Запуск отдельного бота

```powershell
python -m pip install -r requirements-pc.txt
python -m photo_auditor run
```

Используется уже подключённый ChatGPT (`listener.chatgpt_auth`); Codex и API-ключ
не нужны. Поддержка веб-поиска зависит от разрешений выбранного аккаунта/модели.
При отказе поиск не имитируется, результат не одобряется.

В Telegram открыть `https://t.me/foto_auditor_bot` и нажать «Запустить».
Доступ — только владельцу (по умолчанию ID 1264067528, настройка
`PHOTO_AUDIT_OWNER`). Для ручной проверки отправить фото/PNG/JPEG/WEBP-документ
с подписью `Бренд | точная модель`. `/status` показывает очередь.
Отчёт приходит с сопоставлением GENERATED / SOURCE, замечаниями и кликабельными
ссылками. Неполный/непонятный результат нельзя принять за успешную проверку.

Автозапуск после подключения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-photo-auditor-task.ps1
Start-ScheduledTask -TaskName 'AgentsMY Photo Auditor'
```

Сервис слушает только `127.0.0.1:8793`, требует секрет в `X-Audit-Token`.
Внешние порты и дополнительный SSH-туннель не нужны. Журнал без токенов:
`runs/photo-auditor/service.log`. Снимки, сохранённые страницы, эталоны и отчёты:
`runs/photo-auditor/<id>/`.

## Подключение к текущему фотоагенту

Патч: `integrations/fotogen-photo-audit.patch`. Генератор проверяет известные
точки подключения и компилирует результат; при изменении исходника останавливается:

```powershell
python scripts/prepare-photo-auditor-integration.py
```

Он **только формирует патч в этом проекте**, рабочий фотоагент не меняет.
Перед применением: остановить обе дорожки фотоагента в спокойном состоянии,
сохранить копию `remote_agent.py`, проверить существующую очередь выгрузки,
применить патч и добавить этот проект в `PYTHONPATH` окружения фотоагента.
Установить зависимости и запустить службу контроля, затем задать:

```text
PHOTO_AUDIT_ENABLED=1
PHOTO_AUDIT_ROOT=C:\Users\TLT-1\Documents\GitHub\Agents_MY
```

Каждая успешная проверка создаёт разрешение с HMAC, связанное с ID задания и
SHA-256 точного файла. Дополнительная проверка в `_upload_result` защищает
повторную доставку из outbox: старые не проверенные файлы не обходят контроль.
Проверка действует перед outbox и перед загрузкой в Drive/VPS.
На ручном разборе исходная задача помечается ошибкой контроля, снимки сохраняются.
Старые отложенные выгрузки нужно отдельно разобрать перед включением фильтра.

Патч пока не применён. На действующем процессе его включать только после
проверки одного реального изображения и согласованного переключения дорожек.
При откате остановить дорожки, вернуть сохранённый `remote_agent.py` и прежнее
окружение, затем запустить их снова. Не выпускать автоматически ранее задержанные
изображения только из-за выключения контроля.

## Проверки

```powershell
python -m pytest -q --basetemp=runs_test/photo-auditor --tb=short
python -m photo_auditor check C:\path\image.png --brand Midea --model EXACT-MODEL --product-id test-001
```

Вторая команда передаёт указанное изображение подключённому ChatGPT и ищет
эталоны в интернете. Новые изображения не генерируются; сообщений в Telegram
эта команда не отправляет. Реальный прогон требует разрешения на передачу файла.

Официальная документация:
[входные изображения](https://developers.openai.com/api/docs/guides/images-vision),
[веб-поиск и ссылки](https://developers.openai.com/api/docs/guides/tools-web-search),
[возможности и ограничения ChatGPT plan usage](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).
