# Прайсы и документы в Оркестраторе

Можно вставить скопированную таблицу прямо в сообщение или переслать/прикрепить файл в личный чат Оркестратора:

| Источник | Форматы |
| --- | --- |
| Обычный текст | сообщение, TXT |
| Таблицы | CSV, TSV, XLSX, XLS, XLSM, ODS |
| Документы | PDF, DOCX, DOC, RTF |
| Структурированные данные | YAML, YML, JSON |

Пример подписи: «Разбери этот прайс. Генераторы CARVER с положительным остатком в генерацию, наценка 15%». Без поручения на генерацию файл только разбирается; непонятные цены, остатки и наценка требуют уточнения. Можно сначала отправить файл, а затем написать или надиктовать «Из этого файла возьми генераторы, наценка 15%». Ссылка на недавний файл действует 30 минут.

Сохраняются оригинал и SHA-256, названия листов и номера строк/страниц. Товарные строки сверяются двумя отдельными чтениями без истории. Отбор и проверка текущей очереди выполняются после чтения. Публикация остаётся по кнопке владельца. Текст и команды внутри файлов считаются содержимым источника, а не поручениями пользователя.

Если для номенклатуры уже есть готовая или опубликованная карточка, бот присылает отдельное сообщение с датой её задания и сравнением цен. Сохранённая цена берётся только из записи, связанной с конкретным заданием карточки, включая новые партии. Старую цену похожей модели использовать нельзя. Пробел перед суффиксом не меняет модель (`11000 DR` и `11000DR`), но `DR`, `DVR`, `D` и `DE` различаются.

Для конечных цен («добавлять проценты не надо») повторной наценки нет. При заданной наценке сравнивается рассчитанная продажная цена, а не закупочная с продажной. Без известной наценки или сохранённой цены бот просит ручную проверку. Разные цены одной модели в новом источнике помечаются как противоречие. Неподтверждённый разбор даёт предварительную сверку. Цена из задания не считается автоматически проверенной ценой на изображении: это явно отмечается. Сверка не меняет карточки и не запускает повторную генерацию.

Под отдельной сверкой есть действия:

- **Обновить цены**: покажет конкретные суммы и число переделок, затем попросит подтвердить. Каждая подтверждённая цена создаёт ровно один запрос новой карточки; исходник сохраняется, старая версия блокируется на время передачи, результат приходит новым превью. Публикация подтверждается отдельно. Повтор после потери ответа проверяет тот же запрос. Уже опубликованные и заменённые карточки здесь не переделываются.
- **Оставить карточки**: сохранит старые цены без генерации и публикации.
- **Настроить порог**: предложит правило «до 1% включительно оставить, свыше 1% до 5% спросить, свыше 5% повышенное внимание». До явного сохранения правило не действует. Процент считается от старой цены для повышения и снижения; рублёвая разница не подменяет процент. Неизвестные и конфликтующие цены всегда требуют решения. Небольшие изменения после сохранения правила сворачиваются в счётчик.

Можно написать или надиктовать «Обновить цены», «Оставить карточки», «Настроить порог». После настройки можно задать два порога, например «порог 0,5% и 3%», затем сохранить. Разные цены одной модели выбираются кнопкой; отдельно присланная точная сумма также выберет единственный подходящий вариант. Сам выбор суммы ещё не запускает переделку. Сверка доступна через `/prices` и кнопку «💰 Проверка цен».

Отсутствующий бренд в одной строке не означает неполноту всего списка. Если оба чтения подтверждают число строк, известные строки можно ставить отдельно, а строку без бренда — уточнять. Для Excel/CSV и других распознанных таблиц числа и исходные названия привязываются к ячейкам. Противоречивый SKU исключается из новой генерации отдельно. Старая карточка при повторном файле не генерируется заново.

PDF со сканами и вставленные изображения DOCX передаются на распознавание. Excel читается по всем листам, включая скрытые. Макросы и формулы не выполняются: берутся сохранённые результаты Excel; отсутствующий результат формулы остаётся неизвестным. Для DOC нужен системный пакет `antiword`.

Лимиты одного файла: 20 МБ, 120 000 символов извлечённого текста, 200 строк таблиц суммарно с заголовками, 128 столбцов, PDF до 40 страниц, до 8 изображений/сканированных страниц. Превышение выдаёт сообщение с просьбой разделить файл; часть прайса не выдаётся за полный документ. В одной транскрипции — до 200 товарных строк на источник, до 500 всего. Несколько файлов обрабатываются отдельно; ссылка «из файла» выбирает последний подходящий документ. Пароли, архивы и неизвестные форматы не поддерживаются.

Установка на VPS: `pip install -r requirements-vps.txt` в окружении Оркестратора и `apt-get install antiword` для DOC. Миграция SQLite добавляет только поле `messages.document`; существующие сообщения и фотографии сохраняются.

Проверки: `python -m pytest tests/test_document_import.py tests/test_document_flow.py tests/test_document_pending.py tests/test_supplier_documents.py` и общий набор `python -m pytest`. На Windows тестам asyncio нужен доступ к локальным сокетам; при ограничении временной папки укажите `--basetemp runs_test/<новая-папка>`.
