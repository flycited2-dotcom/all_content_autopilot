# Прайсы и документы в Оркестраторе

Можно вставить скопированную таблицу прямо в сообщение или переслать/прикрепить файл в личный чат Оркестратора:

| Источник | Форматы |
| --- | --- |
| Обычный текст | сообщение, TXT |
| Таблицы | CSV, TSV, XLSX, XLS, XLSM, ODS |
| Документы | PDF, DOCX, DOC, RTF |
| Структурированные данные | YAML, YML, JSON |

Пример подписи: «Разбери этот прайс. Генераторы CARVER с положительным остатком в генерацию, наценка 15%». Без поручения на генерацию файл только разбирается; непонятные цены, остатки и наценка требуют уточнения. Можно сначала отправить файл, а затем написать или надиктовать «Из этого файла возьми генераторы, наценка 15%». Ссылка на недавний файл действует 30 минут.

Сохраняются оригинал и SHA-256, названия листов и номера строк/страниц. Товарные строки сверяются двумя отдельными чтениями без истории. Отбор и проверка текущей очереди выполняются после чтения. Публикация остаётся по кнопке владельца. Текст и команды внутри файлов считаются содержимым источника, а не поручениями пользователя.

PDF со сканами и вставленные изображения DOCX передаются на распознавание. Excel читается по всем листам, включая скрытые. Макросы и формулы не выполняются: берутся сохранённые результаты Excel; отсутствующий результат формулы остаётся неизвестным. Для DOC нужен системный пакет `antiword`.

Лимиты одного файла: 20 МБ, 120 000 символов извлечённого текста, 200 строк таблиц суммарно с заголовками, 128 столбцов, PDF до 40 страниц, до 8 изображений/сканированных страниц. Превышение выдаёт сообщение с просьбой разделить файл; часть прайса не выдаётся за полный документ. В одной транскрипции — до 200 товарных строк на источник, до 500 всего. Несколько файлов обрабатываются отдельно; ссылка «из файла» выбирает последний подходящий документ. Пароли, архивы и неизвестные форматы не поддерживаются.

Установка на VPS: `pip install -r requirements-vps.txt` в окружении Оркестратора и `apt-get install antiword` для DOC. Миграция SQLite добавляет только поле `messages.document`; существующие сообщения и фотографии сохраняются.

Проверки: `python -m pytest tests/test_document_import.py tests/test_document_flow.py tests/test_document_pending.py tests/test_supplier_documents.py` и общий набор `python -m pytest`. На Windows тестам asyncio нужен доступ к локальным сокетам; при ограничении временной папки укажите `--basetemp runs_test/<новая-папка>`.
