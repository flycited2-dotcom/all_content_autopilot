# Товары из фотографий поставщика

Владелец отправляет Оркестратору фото прайса и текстовую или голосовую задачу:

> Поставь генераторы CARVER с этих фото в генерацию. Оранжевые числа — входящая цена, синие — остаток. Наценка 15%.

Фото можно отправить перед поручением, после него либо с подписью. Поддерживаются Telegram-фотографии,
JPEG/PNG/WebP файлом и альбомы до восьми изображений. Один файл — до 10 МБ, альбом — до 20 МБ.
Альбом собирается в одну задачу после двух секунд без новых частей. Все части сохраняются в SQLite,
повторная доставка после перезапуска не создаёт новую задачу. Следующий текст ждёт сборки альбома.

## Поведение

- Фотографии получает обработчик диалога: Claude читает проверенные локальные изображения,
  ChatGPT получает настоящие изображения с высоким уровнем детализации. Работник генерации для распознавания не нужен.
  Ожидание Claude для фото ограничено 60 секундами, затем запрос передаётся подключённому резерву.
- Модель переписывает наименование, бренд, точную модель, входящую цену и остаток.
  Поручения, напечатанные внутри скриншота, считаются данными и не исполняются.
- Для задания по фото запрещена подмена товаров позициями каталога. Нечитаемые или противоречивые данные
  требуют уточнения; стоимость, наличие и наценка не угадываются.
- В генерацию поступают только товары нужного бренда с положительным остатком.
  Суффиксы `D`, `DE`, `ID`, `DR`, `DVR` остаются частью модели.
- Продажную цену считает Python `Decimal`: входящая × (1 + наценка / 100), округление half-up до рубля.
  Например: 45 455 × 1,15 = 52 273 ₽ после округления.
- Отправленные заранее фотографии доступны для следующего поручения в течение 30 минут.
  Сохраняются целые недавние альбомы с общим ограничением восемь фото / 20 МБ.
  Новый текстовый прайс можно импортировать отдельно от недавних фотографий.
- Результат попадает в обычный конвейер товаров: исследование → карточка → проверка → превью.
  Сохраняются кнопки отмены/восстановления и обычное согласование публикации владельцем.
  При остановленном работнике товары остаются в очереди, бот показывает фактическое состояние.

## Источники и повторные запросы

В `<каталог state.db>/supplier_imports/<хеш источника>/` сохраняются исходные изображения,
`manifest.json` с ценами/остатками/наценкой и `selection.json` с принятыми ключами.
Скриншот прайса не используется как эталонное фото товара.
Ключи товаров совпадают с обычными `excel|бренд|модель`: повторное фото не создаёт копии уже работающих моделей.

Если процесс оборвался между постановкой и сохранением результата, остаётся `selection-started.json`.
Повторная автоматическая постановка блокируется с явной ошибкой: оператор должен проверить очередь,
чтобы не заказать повторную генерацию. Подтверждённый результат после обычного повтора используется повторно.

## Проверка без постановки в генерацию

Утилита использует уже подключённый ChatGPT, сохраняет только `preview.json` и `preview.md`:

```powershell
python tools/preview_supplier_photo.py C:/path/price.png --instruction "CARVER с фото в генерацию; оранжевое — входящая цена, синее — остаток; наценка 15%" --output runs/supplier-photo-preview
```

Она не вызывает content-factory, не отправляет сообщений в Telegram и не публикует товары.
Изображение передаётся подключённому обработчику ChatGPT; для проверки пользовательского скриншота
в этой сессии владелец дал отдельное согласие.

## Активация

Требуются обновлённые модули `orchestrator_bot` на VPS и `listener` на ПК,
а также актуальная `.claude/commands/chat-turn.md`. Новые зависимости не добавлены:
Pillow уже входит в `requirements-pc.txt`; серверная часть не импортирует Pillow.
Миграции SQLite добавляют поля вложений/альбомов и таблицу идентификаторов частей альбома,
существующие сообщения и журналы сохраняются.

До обновления VPS необходимо сверить его код с локальным и сохранить резервную копию:
рабочая копия проекта содержит другие изменения, поэтому целиком заменять её на сервере без сверки нельзя.
После выкладки перезапустить `orchestrator-bot.service` и слушатель `AgentsMY Listener`.
`GET /health` должен содержать возможность `supplier_photo_import`.
Старый сервер эту возможность не объявляет; новый слушатель не должен обещать импорт по фото до обновления сервера.

перезапущены. Резервная копия кода и SQLite: `/opt/agents-my/backups/autopilot-20261028-142632`.
Миграции проверены, целостность базы — `ok`, сервис — `active`, слушатель передаёт heartbeat.
